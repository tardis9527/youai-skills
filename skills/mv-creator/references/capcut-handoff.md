# 剪映交付

## 素材包内容（`final/capcut/`）

| 目录/文件 | 内容 |
| --- | --- |
| `01_音乐/` | 选定歌曲原文件；有 ffmpeg 且原文件不是 WAV/MP3 时另附 48kHz WAV |
| `02_视频片段/` | 选定的视频片段，文件名 `顺序_镜号_入点-出点.mp4`（秒），按名称排序就是时间线顺序 |
| `03_关键帧/` | 各镜头关键帧，可作封面、静帧补位或剪映"图片转视频"的素材 |
| `04_字幕/lyrics.srt` | 按镜头时间生成的歌词字幕（时间是镜头级的近似值） |
| `04_字幕/voice.srt`（可选） | 按选定配音真实时长生成的句级旁白字幕 |
| `05_节拍/小节线.txt` | 每个小节的起始时间与能量，用于对照卡点 |
| `06_旁白/`（可选） | 逐句原始配音与《声音时间表》Markdown/JSON，含位置、时长、增益、降音及字幕开关 |
| `07_混音参考/`（可选） | `song_only.wav`、`voice_track.wav`、`mix.wav` 与混音版本记录 |
| `剪辑清单.md` | 时间线表：每个镜头的入点、出点、镜头时长、片段时长、段落、歌词、转场建议、缺失项 |

重新运行 `package` 会覆盖同名文件；删掉的镜头留下的旧文件不会自动清除，需要时手动清空该目录后重新生成。

## 剪映导入步骤（交付时告诉用户）

1. 新建草稿，比例选 9:16。把 `01_音乐` 里的歌曲拖到音频轨，从 0 秒开始。
2. 全选 `02_视频片段` 的文件按名称顺序拖入主轨，按《剪辑清单》的入点对齐，把每段尾部多出来的部分裁掉。
3. 音频轨可用"踩点"功能自动标记节拍，与 `05_节拍/小节线.txt` 对照，微调切点到重拍上。
4. 字幕：可以导入 `04_字幕/lyrics.srt`，或用剪映的"识别歌词"重新生成后校对（通常更准）。
5. 画质：H3 片段默认 864×1536、24fps，以项目实际规格为准；可按需要使用剪映的"超清画质""智能补帧"，再导出 1080×1920、30fps。
6. 统一调色：给所有片段套同一个滤镜或 LUT，让各段色调一致。

启用旁白时按 [voice-guide.md](voice-guide.md) 选择一种音频导入方式：

- **继续精剪**：用 `01_音乐/` 原歌曲，在独立音轨按《声音时间表》放置 `06_旁白/` 的逐句音频。歌曲基础增益默认 -3dB、旁白 0dB；以时间表的实际增益为准，旁白期间歌曲默认再降低 6dB，约 0.15 秒进入、0.25 秒恢复，试听后微调。
- **沿用已试听混音**：只使用 `07_混音参考/mix.wav`，不要再叠加原歌曲、旁白轨或逐句音频。`song_only.wav` 已应用基础歌曲增益，`voice_track.wav` 已排列好位置，可用于分轨调整。

所有视频片段原音轨静音。歌词字幕放下方，旁白字幕放上方，分别导入并校对；关闭字幕的语气声不会进入 `voice.srt`。48kHz 交付统一剪辑规格，不增加 Breeze 原始 24kHz 音频的细节。换歌、改时间或改配音后重新 `package`，以当前 `package.json` 与剪辑清单为准；历史文件不会自动清理。

## 粗剪参考（`final/roughcut.mp4`）

`roughcut` 把选定片段按分镜时间裁切（片段不够长时定格最后一帧），拼接后合入歌曲，用来快速看整体节奏和故事是否通顺，不作为成片。缺视频的镜头用关键帧静帧或黑场代替，命令会列出这些镜头。`--burn-subs` 另出一版带歌词字幕的视频（需要 ffmpeg 带 libass，Windows 版 ffmpeg 一般已包含）。

启用旁白后同时输出 `roughcut_voice.mp4`；`--burn-subs` 另输出 `roughcut_voice_subs.mp4`（有字幕时）。原歌曲版仍保留，方便 A/B 试听。正式交付前需试听台词完整性、歌词与旁白可懂度、语气和音量，波形峰值限制不能替代听感验收。
