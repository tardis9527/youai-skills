# 剪映交付

## 素材包内容（`final/capcut/`）

| 目录/文件 | 内容 |
| --- | --- |
| `01_音乐/` | 选定歌曲原文件；有 ffmpeg 且原文件不是 WAV/MP3 时另附 48kHz WAV |
| `02_视频片段/` | 选定的视频片段，文件名 `顺序_镜号_入点-出点.mp4`（秒），按名称排序就是时间线顺序 |
| `03_关键帧/` | 各镜头关键帧，可作封面、静帧补位或剪映"图片转视频"的素材 |
| `04_字幕/lyrics.srt` | 按镜头时间生成的歌词字幕（时间是镜头级的近似值） |
| `05_节拍/小节线.txt` | 每个小节的起始时间与能量，用于对照卡点 |
| `剪辑清单.md` | 时间线表：每个镜头的入点、出点、镜头时长、片段时长、段落、歌词、转场建议、缺失项 |

重新运行 `package` 会覆盖同名文件；删掉的镜头留下的旧文件不会自动清除，需要时手动清空该目录后重新生成。

## 剪映导入步骤（交付时告诉用户）

1. 新建草稿，比例选 9:16。把 `01_音乐` 里的歌曲拖到音频轨，从 0 秒开始。
2. 全选 `02_视频片段` 的文件按名称顺序拖入主轨，按《剪辑清单》的入点对齐，把每段尾部多出来的部分裁掉。
3. 音频轨可用"踩点"功能自动标记节拍，与 `05_节拍/小节线.txt` 对照，微调切点到重拍上。
4. 字幕：可以导入 `04_字幕/lyrics.srt`，或用剪映的"识别歌词"重新生成后校对（通常更准）。
5. 画质：片段原始是 720×1280、16fps，可用剪映的"超清画质""智能补帧"提升，再导出 1080×1920、30fps。
6. 统一调色：给所有片段套同一个滤镜或 LUT，让各段色调一致。

## 粗剪参考（`final/roughcut.mp4`）

`roughcut` 把选定片段按分镜时间裁切（片段不够长时定格最后一帧），拼接后合入歌曲，用来快速看整体节奏和故事是否通顺，不作为成片。缺视频的镜头用关键帧静帧或黑场代替，命令会列出这些镜头。`--burn-subs` 另出一版带歌词字幕的视频（需要 ffmpeg 带 libass，Windows 版 ffmpeg 一般已包含）。
