# 歌词段落导演标注

图片中的 `[Pre-Chorus - 情绪往下压，鼓轻进]`、`[Chorus - 全乐队进，弦乐推开，男声直给，不嘶吼]` 这类写法有用，但要把它定位为**创作与制作标注**，不是模型一定会执行的歌词语法。

## 统一输出契约：三层分离

完整歌曲的歌词资料默认分成三层，三层使用同一组 `section_id`，但承担不同任务：

1. **段落计划（Section Plan）**：结构化记录每段的叙事功能、情绪弧线、能量、演唱、节奏、配器、衔接和状态。它是创作控制卡，不是歌词。
2. **导演版歌词（Director Lyrics）**：给人阅读、复盘和继续制作；在段落标题中保留 2–4 个最重要的可听动作。
3. **模型版 Lyrics（Model Lyrics）**：可直接粘贴到模型歌词框；只保留基础段落标签和实际要唱的字，不放解释、行号、制作指令或未授权台词。

三层必须逐段对应。导演版可以比模型版详细，模型版不能凭空增加段落、台词、和声或即兴。

推荐的段落计划字段如下，普通作品只填写有作用的字段：

```yaml
- section_id: V1
  tag: Verse
  function: 交代人物与当前处境
  emotion: 克制、带一点回望
  energy: 2
  vocal: 近麦、半说半唱、清晰咬字
  rhythm: 松弛四拍，句间留白
  arrangement: 木吉他单独托底，低频暂不进入
  transition: 最后一句保留悬念，鼓在下一段轻进
  lyric_density: medium
  status: planned
```

`energy` 只表示设计阶段的相对等级（1–5），不代表音频实测；`status` 在没有试听时保持 `planned`。不为填满字段虚构 BPM、调号、精确秒数或声部。

## 为什么有用

- 它把“悲伤、燃、治愈、高级”转成每一段可检查的动作：能量如何变化、谁进入或退出、主唱怎么唱、下一段如何接。
- 它能固定情绪弧线，避免模型把整首歌压成同一种音量、密度和唱法。
- 它便于修改：如果试听后副歌不够打开，可以只改副歌标注和对应的 `Vocal Details` / `Arrangement`，不必重写整首歌词。

它不能保证模型逐条遵循。方括号中的制作说明可能被当成歌词唱出，括号或标题也不能替代真实的模型字段。因此完整交付默认保留两层文本：

1. **导演版歌词**：给人阅读、复盘和继续制作，保留段落标注。
2. **模型版 Lyrics**：只保留已核实的段落标签和实际要唱的字，去掉导演说明。

导演版中的控制意图还要分别映射到 MiniMax 的 `Vocal Details` / `Arrangement` 或 YuE2 的自然 `Style`。只有模型明确支持且用户要求做实验时，才另给带扩展标签的实验版，并标为待试听。

## 推荐写法

每个主要段落一行，使用“段落名 + 2–4 个动作”，不要写成泛泛情绪词，也不要把所有技术参数塞进括号。动作优先按“情绪变化 → 演唱 → 节奏/密度 → 声部进入退出 → 衔接”排序；一行放不下时，拆到段落计划或模型描述。

```text
[Verse 1｜情绪压低，像在回忆；木吉他单独托底，男声近麦、克制，句间留白]
[Pre-Chorus｜逐步收紧，鼓点轻进；主唱抬高语气但不提高音量，最后一句留悬念]
[Chorus｜全乐队进入，弦乐向外推；男声直接有力、不嘶吼；核心句拉开并留出回应空间]
[Bridge｜鼓和低频收掉，只留钢琴与箱琴；人声更近、更像自言自语，结尾停一拍接回副歌]
[Outro｜回到 Intro 的古琴动机，声部逐层退出；近麦人声说完最后一句，箫尾音自然散开]
```

“情绪往下压”要同时写成可听动作，例如降低密度、收掉鼓、缩窄音区或改为近麦；“全乐队进”要说明进入哪些声部及其职责；“不嘶吼”要落到清晰、直接、受控的力度。不要只写“更有情绪”“更高级”。

## 歌词正文规则

- **段落职责先于段落数量**：Intro 建立音色或场景；Verse 推进人物、动作或信息；Pre-Chorus 收紧并制造期待；Chorus 提出核心态度；Bridge 提供新角度、时间跳转或编曲减法；Outro 完成收束。未承担功能的段落删除，不为模板硬加 Bridge、Rap 或 Post-Chorus。
- **每行是一口气或一个语义单元**：在自然停顿、动作转折或重音前换行。不要为了视觉整齐强行等字数，也不要把一整段散文塞在一行。行长差异应由唱法和目标时长解释。
- **副歌要有可辨认核心**：保留一句或一个短动机形成识别；后次重复可以通过新信息、回应声部、和声或配器发展，但不能只把“同上”写进交付稿。
- **第二主歌必须检查信息增量**：至少新增一个动作、处境、视角或结论；如果用户要求逐字重复，记录为明确选择，不擅自改词。
- **节奏写相对动作，速度写全局**：段落里写“半拍感、切分、句间留白、鼓轻进、密度加倍”等相对变化；BPM、拍号和调性放 Music Brief/Caption/Style，未选时不在歌词标题里臆造。
- **正文不承担制作控制**：括号、破折号、连续省略号、全角空格和重复字母不当作可靠的延音、换气或音效指令；需要这些效果时写进导演版、Caption/Style 或 vocal event。
- **授权决定能否写进正文**：固定念白、固定衬词和指定回应只有在用户授权后才进入模型版 Lyrics；自由 Ad-lib 只写允许的范围，不伪造具体台词。用户原词逐字保留时，导演标注也不能改动原文。
- **语言和发声分开**：歌词保留实际演唱文字与字形；普通话、粤语、英语等演唱语言写入 Caption/Style，不用曲风词替代语言。

### 标准段落顺序与可选项

默认从下列标签中选择实际需要的部分，并按歌曲功能排序：

```text
[Intro]
[Verse 1]
[Pre-Chorus]
[Chorus]
[Verse 2]
[Pre-Chorus 2]
[Chorus 2]
[Bridge]
[Final Chorus]
[Outro]
```

`[Post-Chorus]`、`[Instrumental]`、`[Solo]` 只有在承担明确的旋律、律动或过渡任务时使用。模型版优先采用基础英文标签；导演版可在同一 `section_id` 后补中文说明。

## 何时写、写到哪里

| 信息 | 导演版标注 | 模型输入 |
| --- | --- | --- |
| 段落功能 | 保留 | 用基础 `[Verse]` / `[Chorus]` 等标签，功能写进描述 |
| 情绪与能量 | 写成变化动作 | 转成演唱力度、音区、密度和声部进入退出 |
| 演唱姿态 | 写清近麦、直给、克制、说话感等 | MiniMax 放 `Vocal Details`；YuE2 放 `Style` |
| 编曲变化 | 写谁进、谁退、如何衔接 | MiniMax 放 `Arrangement`；YuE2 放 `Style` |
| 固定念白/衬词 | 只在获授权时保留实际字句 | 同样放入对应 Lyrics 段落 |
| 自由即兴 | 写允许范围，不伪造具体台词 | 用自然描述说明范围，不能靠括号授权 |

## 交付和自查

完整歌曲默认按以下顺序组织：共同 Music Brief → Section Plan → 导演版歌词（带标注）→ 模型版 Lyrics → MiniMax Caption → YuE2 Style。若用户只要歌词，仍按“导演版 + 模型版”交付；若用户明确要求可直接粘贴，则把干净模型版放在最前，并把导演说明放到代码块外。

交付前检查：

- 每个标注都能映射到一个歌词、表演或编曲动作。
- Section Plan、导演版和模型版使用同一组 `section_id`，段落没有错位或遗漏。
- 标注中的段落与实际歌词一致，没有凭空增加 Bridge、Rap 或 Outro。
- 模型版 Lyrics 不含情绪解释、角色标题、行号、制作指令或未核实的扩展标签。
- 每行断句基本符合自然语义和预期换气；副歌核心句可辨，第二主歌有信息增量或明确的逐字重复授权。
- 段落内的节奏说明写相对变化，BPM/拍号等全局参数没有偷偷混进歌词正文。
- 固定台词、衬词和原词权限清楚；没有把导演标注误当成用户授权。
- 试听反馈能定位到段落标注：能量、主唱、声部进入退出、衔接或收尾至少分开记录。

这套标注是规划层，状态仍应写 `planned`；没有真实音频时，不把“男声直给”“弦乐推开”写成已经听到或稳定复现的结果。
