# 提示词与判断指南

这份指南同时适用于内置 `image_gen` 和经用户选择的 CLI。CLI 的 `quality`、遮罩、输出格式、路径等控制项见 [CLI 操作说明](cli.md)。

## 写提示词

建议顺序：场景 → 主体 → 关键细节 → 构图 → 必须保留/避免的内容 → 用途。按实际需要选择字段，不必机械填满。

```text
用途分类：<下方的英文 slug>
素材用途：<网页首图、游戏贴图、商品照片等>
主要需求：<用户原始要求>
输入图片：<图 1：编辑目标；图 2：风格参考>（可选）
场景：<环境>
主体：<最重要的人或物>
媒介/风格：<摄影、插画、3D 等>
构图：<远近、视角、留白等>
光线/氛围：<需要时填写>
画面文字（逐字）："<必须准确出现的文字>"
约束：<必须保留的内容>
避免：<不应出现的内容>
```

- 原要求已详细时，只整理表达，不加新的创意设定。原要求笼统时，可补有助于成图的构图、用途和合理场景细节。
- 不凭空添加人物、道具、品牌色、文案或剧情。左右留白只在版面确有需要时指定。
- 编辑时写清“只修改 X，保持 Y 不变”，每次迭代都重复关键不变量。
- 画面文字使用引号，指定字形与位置；生图后逐字检查。不常见词可逐字母/逐字写出。
- 多输入图用编号标清角色。参考图不是默认的编辑目标。
- 透明图明确要求真实透明背景，并检查 alpha 与边缘，不要把白底图当作透明图。

## 分类标签

这些 slug 沿用内置 Skill，便于在提示词和 CLI 中保持一致。

| 生成 | 适用内容 |
| --- | --- |
| `photorealistic-natural` | 自然写实摄影 |
| `product-mockup` | 产品、包装、商品陈列 |
| `ui-mockup` | 界面样稿；说明保真度 |
| `infographic-diagram` | 信息图和结构示意 |
| `scientific-educational` | 科学教学图，强调标注和准确性 |
| `ads-marketing` | 广告创意，文案需逐字指定 |
| `productivity-visual` | 幻灯片、图表、工作流程 |
| `logo-brand` | 标志概念；若已有可编辑矢量体系，直接改原文件 |
| `illustration-story` | 漫画、绘本、叙事插画 |
| `stylized-concept` | 风格化概念图、3D 风格图 |
| `historical-scene` | 需符合年代细节的场景 |

| 编辑 | 适用内容 |
| --- | --- |
| `text-localization` | 替换画面文字，保持布局 |
| `identity-preserve` | 保留人物身份、姿态的换装或换景 |
| `precise-object-edit` | 精确移除或替换物体 |
| `lighting-weather` | 只改光照、季节、天气 |
| `background-extraction` | 抠图和透明背景 |
| `style-transfer` | 参考图风格迁移 |
| `compositing` | 多图合成，匹配比例与光影 |
| `sketch-to-render` | 草图转成品，保持透视与比例 |

## 中文示例

**新图：产品页首图**

```text
用途分类：product-mockup
素材用途：产品页首图
主要需求：一只哑光陶瓷咖啡杯的商品照片
媒介/风格：真实产品摄影
构图：横幅；杯子完整可见；保留放置网页文案的空间
光线/氛围：柔和摄影棚光
约束：无商标、无画面文字、无水印
```

**编辑：更换背景**

```text
用途分类：precise-object-edit
输入图片：图 1：要编辑的商品照片
主要需求：仅将背景改为暖色日落场景
约束：商品、边缘、标签与构图保持不变；无新增文字
```

**编辑：透明抠图**

```text
用途分类：background-extraction
输入图片：图 1：要抠出的原图
主要需求：去除背景，输出带真实 alpha 通道的透明 PNG
约束：保留主体轮廓、细小边缘和原有文字；无白边、无重绘
```
