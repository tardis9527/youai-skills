# 📂 使用示例与体验教程

本目录包含部分 Skill 的产出样例，帮助你直观理解 Skill 的输出效果。

现有示例基于同一个虚构产品 **TeamLog（团队日报助手）** 人工编写，用于展示部分 Skill 之间的上下游串联关系。样例中的市场估算、用户画像、成本和目标值是演示设定，不能作为已核实的数据或实测效果引用。

## 先体验核心工作流

[中文体验教程](./teamlog-walkthrough.md) · [English walkthrough](./teamlog-walkthrough_en.md)

教程提供“需求探索 → PRD → 原型方案”的可复制输入、交接路径和人工检查点，适合运行自己的版本。教程不是实际运行记录；下面的样例是精简参考，不保证通过当前完整产物校验。
