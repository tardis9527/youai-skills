# tardis-music 行为回归场景

这些是模拟输入和验收标准，不是已经运行的音频案例或真实用户偏好。静态校验只证明格式/引用有效，文本前向试用只证明对应输入的文本行为；音乐表现需用户手动生成后试听。评估时使用隔离输出目录，不写真实 `_learning/`，记录实际回复与结果，不能只匹配关键词。

## 执行记录要求

记录日期、Skill 版本/工作区状态、原始输入与可用素材、实际回复、检查范围、观察到的问题和修复后结果。独立试用者只得到请求与所需原始上下文，不先给预期答案。由维护者按上述标准判断，不能将模拟故事写入真实偏好，也不能将文本检查描述成 GPU/音频/平台成效验证。

## 2026-11-05 执行范围

本次独立试用共 7 次：原词单模型交付、模糊毕业需求、无人声/旁白冲突、按场景复用偏好与收尾反馈、毕业需求复测、隔离项目反馈/偏好实际读写、未指定模型的纯音乐完整交付。首次毕业回复把多个缺口放进一个编号，已据此修订采访规则并复测。

另实际核对了本地引用、YAML/JSON 示例、技能元数据、两份 workflow 的连接与保存分支、插件同步；隔离学习记录经结构读取确认保留旧偏好、仅新增授权范围、未知实测值为 null 且未创建歌曲修订。完整模拟回复保存在本地忽略目录 `output/skill-validation/tardis-music-forward.md`；模拟档案只存在隔离测试项目，不进入 Skill 包。

上述是部分场景的文本与文件验证，不代表 16 项全部前向执行；未运行 ComfyUI、真实音频生成/试听或平台传播验证。
